Derivatives

The slope of the tangent line at any point

Practice Problems

Apply what you've learned

Problem 1: Finding Derivatives

Given f(x) = x² + 3x, find f'(2).

f'(x) = \boxed{?}
Hint: Use the power rule: d/dx[xⁿ] = n·xⁿ⁻¹. Then evaluate at x = 2.

Problem 2: Definite Integral

Calculate ∫₀² (3x² + 1) dx.

\int_0^2 (3x^2 + 1)\,dx = \boxed{?}
Hint: Find the antiderivative first: x³ + x. Then use the Fundamental Theorem of Calculus.

Problem 3: Limit Evaluation

Evaluate limₓ→₀ (sin x)/x.

\lim_{x \to 0} \frac{\sin x}{x} = \boxed{?}
Hint: This is a fundamental limit. Try using L'Hôpital's rule or the squeeze theorem.
